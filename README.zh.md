# 发匣 Faxia

[English](README.md)

![发匣 Logo](https://raw.githubusercontent.com/KylinLabAI/FaXia-App/master/resources/logo_256.png)

一次创作，多平台发布。发匣支持将 Markdown 内容发布到 GitHub Pages、微信公众号、知乎、掘金、头条号、微博、Reddit、X/Twitter、Medium、Facebook、LinkedIn 等 11+ 平台。

## 功能特性

- **11+ 平台支持** — 原生适配 GitHub Pages、微信公众号、知乎、掘金、头条号、微博、Reddit、X/Twitter、Medium、Facebook、LinkedIn
- **图片自动上传** — Markdown 中的本地图片自动上传到各平台图床
- **智能更新** — 更新已发布文章而非重复发帖
- **命令行 & 桌面端** — 支持 CLI 命令行工具和 Electron 桌面应用
- **平台定制版本** — 为不同平台发布不同版本的内容
- **演练模式** — 验证凭证并预览发布过程，不实际发帖

## 快速开始

1. 下载对应平台的安装包
2. 运行安装程序并按照提示操作
3. 启动发匣
4. 在设置中配置各平台的凭证
5. 用 Markdown 编写文章（可选添加 YAML frontmatter）
6. 点击发布按钮或运行 `faxia publish article.md`
