# FaXia

[中文介绍](README.zh.md)

![FaXia Logo](https://raw.githubusercontent.com/KylinLabAI/FaXia-App/master/resources/logo_256.png)

One creation, multi-platform publishing. FaXia supports publishing Markdown content to 11+ platforms including GitHub Pages, WeChat Official Account, Zhihu, Juejin, Toutiao, Weibo, Reddit, X/Twitter, Medium, Facebook, and LinkedIn.

## Features

- **11+ Platforms** — Native support for GitHub Pages, WeChat Official Account, Zhihu, Juejin, Toutiao, Weibo, Reddit, X/Twitter, Medium, Facebook, LinkedIn
- **Automatic Image Upload** — Local images in Markdown are automatically uploaded to each platform's image hosting
- **Smart Updates** — Updates existing articles instead of creating duplicates
- **CLI & Desktop** — Choose between command line interface or Electron desktop app
- **Platform-Specific Versions** — Publish different versions to different platforms
- **Dry-Run Mode** — Validate credentials and preview publishing without actual posting

## Quick Start

1. Download the installer for your platform
2. Run the installer and follow the prompts
3. Launch FaXia
4. Configure credentials for each platform in Settings
5. Write your article in Markdown with optional YAML frontmatter
6. Click Publish or run `faxia publish article.md`
