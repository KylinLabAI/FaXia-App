## 内容创作者指南

### 入门

#### 任务：安装发匣

**前提条件：**
- Windows 10+（x64）、macOS 11+，或 Ubuntu 20.04+ / Fedora 36+（x64）
- Node.js 20+（CLI 用户）

**操作步骤：**

1. 从 [Gitee 发布页面](https://gitee.com/KylinLab/FaXia-App/releases/latest) 下载安装包
   - 您将看到：下载页面，包含适用于您平台的安装包

2. 运行安装程序并按照提示操作
   - 您将看到：安装向导，引导您完成安装

3. 从应用程序文件夹或开始菜单启动发匣
   - 您将看到：主应用窗口，包含四个标签页：发布、已发布、评论、设置

**预期结果：** 发匣安装成功并正常运行

**常见问题：**

| 问题 | 解决方案 |
|------|----------|
| 系统安全阻止安装 | 进入系统偏好设置/设置，允许来自"未知来源"的应用 |
| CLI 命令未找到 | 运行 `npm install -g faxia` 或确保 Node.js 在 PATH 中 |

#### 任务：配置平台凭证

**前提条件：**
- 发匣已安装并运行
- 您在要发布的平台上有账号

**操作步骤：**

1. 点击设置标签页
   - 您将看到：设置页面，包含数据目录、博客数据和平台凭证部分

2. 为每个要配置的平台：
   - 点击平台名称
   - 输入所需凭证（API 令牌、应用 ID、密钥等）
   - 点击保存

3. 点击"检查凭证"验证所有配置的平台是否正常工作
   - 您将看到：状态指示器，显示每个平台的成功或失败

**预期结果：** 所有配置的平台显示"已连接"状态

**常见问题：**

| 问题 | 解决方案 |
|------|----------|
| 凭证被拒绝 | 仔细检查 API 令牌，确保有足够的权限 |
| 知乎认证失败 | 使用 `npx playwright install chromium` 安装 Playwright，并使用 Playwright 模式 |

### 日常操作

#### 任务：发布文章

**前提条件：**
- 平台凭证已配置并验证
- 您有准备好发布的 Markdown 文章

**操作步骤：**

1. 点击发布标签页
   - 您将看到：发布界面，包含模式选择和文件上传

2. 选择发布模式：
   - 单平台：从下拉菜单选择一个平台
   - 所有平台：同时发布到所有已配置的平台

3. 点击"选择文件"并选择您的 Markdown 文件
   - 您将看到：文件已选择，可预览

4. （可选）启用"演练模式"预览发布过程而不实际发布
   - 您将看到：发布过程预览

5. 点击"发布"
   - 您将看到：每个平台的进度指示器，显示成功或失败

**预期结果：** 文章发布到选定平台，提供直达链接

**常见问题：**

| 问题 | 解决方案 |
|------|----------|
| 图片上传失败 | 检查 Markdown 中的图片引用是否正确，以及平台是否有图片上传配额 |
| 某个平台失败 | 检查平台特定问题（API 速率限制、内容限制） |

#### 任务：更新已发布文章

**前提条件：**
- 文章之前通过发匣发布过
- 您已更新了 Markdown 文件

**操作步骤：**

1. 点击已发布标签页
   - 您将看到：所有已发布文章的列表

2. 找到要更新的文章并点击"更新"
   - 您将看到：确认对话框，显示文章详情

3. 选择更新后的 Markdown 文件
   - 您将看到：更改预览

4. 点击"更新"重新发布
   - 您将看到：每个平台的进度指示器

**预期结果：** 所有平台上的现有文章都已更新

**常见问题：**

| 问题 | 解决方案 |
|------|----------|
| 更新未找到 | 确保文章最初是通过发匣发布的 |

#### 任务：监控评论

**前提条件：**
- 平台凭证已配置
- 文章已发布并收到评论

**操作步骤：**

1. 点击评论标签页
   - 您将看到：所有已连接平台的评论集中视图

2. 按平台或状态（新、已回复、已解决）筛选评论
   - 您将看到：筛选后的评论列表

3. 点击评论查看详情并回复
   - 您将看到：评论详情面板，包含回复选项

**预期结果：** 评论显示在一个界面中，可以进行管理

**常见问题：**

| 问题 | 解决方案 |
|------|----------|
| 评论未加载 | 检查平台 API 凭证和速率限制 |

### 设置

#### 任务：配置数据目录

**前提条件：**
- 发匣正在运行

**操作步骤：**

1. 点击设置标签页
2. 点击"数据目录"部分
3. 点击"浏览"选择存储博客数据的文件夹
4. 点击"保存"

**预期结果：** 数据目录已更新

#### 任务：配置博客设置

**前提条件：**
- 发匣正在运行

**操作步骤：**

1. 点击设置标签页
2. 点击"博客数据"部分
3. 设置默认博客目录
4. 配置文章文件命名约定
5. 点击"保存"

**预期结果：** 博客设置已更新

## 附录

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl/Cmd + P | 打开发布标签页 |
| Ctrl/Cmd + L | 打开已发布标签页 |
| Ctrl/Cmd + C | 打开评论标签页 |
| Ctrl/Cmd + S | 打开设置标签页 |
| Ctrl/Cmd + Enter | 发布文章 |

### 术语表

| 术语 | 定义 |
|------|------|
| CLI | 命令行界面 - 面向高级用户的基于文本的界面 |
| 演练模式 | 预览模式，模拟发布过程但不实际发帖 |
| Frontmatter | Markdown 文件顶部的 YAML 元数据，用于标题、标签等 |
| Playwright | 浏览器自动化工具，用于没有官方 API 的平台 |
