2/5
FaXia publishes your Markdown to 11+ platforms simultaneously:

• GitHub Pages
• WeChat, Zhihu, Juejin, Toutiao, Weibo
• Medium, Reddit, X, Facebook, LinkedIn

All at once. All in parallel. One command: `faxia publish post.md`

#indiedev

3/5
What makes it different:

🖼️ Auto image upload + URL rewrite per platform
🔄 Smart updates — no duplicate posts
🏠 Local-only — your credentials never leave your device
🖥️ CLI + Electron desktop app
🔍 Dry-run mode before you publish
📂 Platform-specific article versions

4/5
Quick start:
```
npm install -g faxia
faxia publish my-article.md
```

Or use the desktop app — drag, select platforms, click publish.

All open source (MIT). No cloud, no tracking.
